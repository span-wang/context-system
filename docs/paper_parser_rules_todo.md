# Paper Parser Rules TODO

这份文档用于重建“本地规则切题”管道。

目标不是在现有全文正则逻辑上继续打补丁，而是重做一套可迭代的规则引擎，满足：

- 先保守切题，再保守抽字段
- 规则结果可解释、可评估、可回归
- 低置信样本可以稳定流转到 `LLM` 或人工标注
- 规则与训练数据之间形成长期闭环

当前统一输出字段至少包括：

- `question_type`
- `question_no`
- `stem_text`
- `options`
- `answer_text`
- `analysis_text`

内部运行时建议额外保留：

- `section_title`
- `raw_text`
- `context_text`
- `confidence`
- `issues`

---

## 1. 总体分期

### P0

先把“题目边界切稳”。

本阶段只追求：

- 版面顺序正确
- 分区基本正确
- 题目边界基本正确
- 常见选择题 / 判断题 / 填空题 / 简答题可切开

本阶段不追求：

- 所有题型都高精度
- 集中答案区和集中解析区完全映射
- 学科定制优化

### P1

把“字段抽取”和“答案解析回填”做完整。

本阶段重点：

- 题干、选项、答案、解析抽取
- 集中答案区 / 集中解析区映射
- 题型推断
- 质量校验与打分

### P2

做“复杂场景增强”和“生产闭环”。

本阶段重点：

- 材料题 / 共享题干 / 跨页题增强
- 双栏和复杂版面增强
- profile 配置化
- 指标体系、样本回流、规则迭代机制

## 2.4 P0 文本标准化与噪音清理

### [ ] P0-008 实现 TextNormalizer

只做弱规范化：

- 统一换行
- 统一全半角
- 统一括号和点号
- 清理多余空白

禁止：

- 语义纠错
- OCR 猜词修复
- 替换占位符

验收：

- 不破坏题干原意
- 规范化结果可复现

### [ ] P0-009 实现 NoiseFilter

目标：

- 去掉页眉、页脚、页码、重复提示、广告文案

规则：

- 跨页重复
- 顶部/底部区域短文本
- 命中噪音词典

要求：

- 不能误删 `答案`、`解析`、`A.` 这类高价值短行

验收：

- 噪音行会被标记或移除
- 误删率可控

- `body_zone`

规则：

- 出现连续高密度答案编号模式时切 `answer_zone`

目标：

## 7. 明确不做

以下内容不应进入规则引擎主职责：

- 自动补全缺失题意
- 自动修复 OCR 语义错误
- 自动生成答案或解析
- 用规则强行“猜”复杂题型语义

这些应交给：

- `LLM`
- 人工标注
- 后续题目增强模块
