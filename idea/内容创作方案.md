# 内容创作方案

## 1. 项目内容定位

这个项目最有价值的方向，不是“AI 帮你写一篇小红书”，而是把真题、资料、知识点、题库、分析结果，持续加工成一套内容工厂。

你现在已经有：

- 素材库
- 内容生成
- 内容审查
- 工作流
- 导出发布
- 真题分析
- 题库与学习数据能力雏形

最适合走的路线是：

`资料沉淀 -> 结构化解析 -> 内容生成 -> 内容审查 -> 发布复盘 -> 训练承接 -> 数据回流`


## 2. 内容方向建议

最适合你的内容，不是泛知识，而是高意图备考内容，建议固定成 4 类。

### 2.1 引流款

用于抢搜索、互动、评论和轻收藏。

- 口诀
- 易错对比
- 高频陷阱

### 2.2 收藏款

用于做高收藏、高转发、高复习价值。

- 三色笔记
- 考前 N 页纸
- 公式/分录大全

### 2.3 信任款

用于证明专业度和建立付费前信任。

- 真题串讲
- 高频考点趋势
- 章节重点拆解

### 2.4 转化款

用于承接用户下一步动作。

- 专题题包
- 模考建议
- 冲刺学习计划


## 3. 现有 6 种内容类型的角色定位

建议把你当前已经实现的内容类型固定角色，不要混着用。

- `mnemonic`：做日更短内容，抢记忆点
- `compare_table`：做高互动、高收藏的易错内容
- `tri_color`：做核心系列内容，沉淀账号风格
- `summary_pages`：做考前节点爆发内容
- `formula_dict`：做搜索型、资料型内容
- `exam_review`：做专业度和转化承接内容


## 4. 内容生产打法

你现在最该做的，不是继续增加“能生成什么”，而是把“一份资料能拆出多少内容”做出来。

建议固定成一源多稿：

- 1 份真题或讲义
- 1 篇真题串讲
- 1 张易错对比
- 1 份三色笔记
- 1 个口诀卡片
- 1 份考前速记页

这样你不是“写一篇内容”，而是在“做内容资产复用”。


## 5. 执行方案

建议按下面的流程跑。

### 5.1 素材库阶段

- 只收高价值资料
- 强制打标签：`学科 / 类目 / 章节 / 年份 / 权威度 / 适用阶段`

### 5.2 选题阶段

每周先从真题分析和高频错点里选题，不要从空白开始想。

优先来源：

- 高频考点
- 近 3 年上升考点
- 高错题
- 模考失分集中点
- 高收藏旧内容对应考点

### 5.3 工作流阶段

每个选题固定填写：

- 内容目标
- 目标人群
- 发布渠道
- 素材引用

### 5.4 生成阶段

同一个选题建议一次生成 3 个版本：

- 引流版
- 收藏版
- 转化版

### 5.5 审查阶段

- 默认走 `hybrid` 审查
- 人工只重点修改标题、开头钩子、结尾 CTA、风险表达

### 5.6 发布复盘阶段

发布后回填结果：

- 浏览
- 点赞
- 收藏
- 评论
- 私信
- 转化到题包或模考的人数


## 6. 最值得补的 3 个能力

- `分析结果 -> 自动创建选题`
- `一源多稿 / 一题多稿`
- `发布后数据回流`

如果只能先做一件事，优先把“选题来源”从人工脑暴切到“高频考点 + 易错点 + 真题分析”。


## 7. 专属内容矩阵

建议整个项目围绕同一个主键组织内容：

`学科 > 类目 > 章节 > 考点 > 题型 > 备考阶段`

以后每篇内容、每套题、每个分析报告，都挂在这套主键上，板块自然能联动。

### 7.1 板块划分

| 板块 | 用户需求 | 适合内容 | 对应现有能力 | 作用 |
|---|---|---|---|---|
| 高频考点板块 | 不知道先学什么 | 三色笔记、考前 N 页纸 | `analysis` + `summary_pages` + `tri_color` | 做认知入口 |
| 易错纠偏板块 | 学了但总做错 | 易错对比、口诀 | `compare_table` + `mnemonic` + 后续错题数据 | 做互动和收藏 |
| 真题拆解板块 | 想知道怎么考 | 真题串讲、题眼拆解 | `papers/questions` + `exam_review` | 建立专业信任 |
| 速记资料板块 | 临考想快速过一遍 | 公式/分录大全、考前速记页 | `formula_dict` + `summary_pages` | 做高收藏资料 |
| 训练提分板块 | 看完想练 | 专题题包、模考卷 | `question-bank` + `practice-sets` + `mock-exams` | 做转化承接 |
| 学习陪跑板块 | 想持续坚持和复盘 | 学习计划、周复盘、掌握度提醒 | `learners` + `learning` + `analysis reports` | 做留存和复购 |


## 8. 板块之间怎么连起来

重点不是多做几个栏目，而是让所有栏目围绕同一个考点节点展开。

### 8.1 用统一标签串起来

每个选题、每篇内容、每套题，都必须带上这些字段：

- `subject`
- `category`
- `chapter`
- `knowledge_point`
- `question_type`
- `target_stage`

没有这些标签的内容，不进入工作流。

### 8.2 用分析结果做选题源头

不要从空白脑暴选题，固定从这些地方出题：

- 高频考点
- 近 3 年上升考点
- 高错题
- 高收藏旧内容对应考点
- 模考失分集中点

### 8.3 用“一考点多形态”做内容拆分

同一个考点建议拆成一组内容：

- 引流版：口诀 or 易错对比
- 信任版：真题串讲
- 收藏版：三色笔记 or 考前 N 页纸
- 转化版：专题题包 or 模考练习

### 8.4 用工作流做串联中枢

你现有的 `workflow` 很适合做总控台。建议每个 topic 固定补这些字段：

- `topic_source`：来自高频考点 / 错题 / 真题 / 人工选题
- `knowledge_point_id`
- `question_ids`
- `funnel_stage`：引流 / 信任 / 转化 / 留存
- `next_action`：发帖 / 导出 / 组题 / 复盘

### 8.5 用发布结果反哺分析

`history` 不要只存生成记录，建议补内容效果数据：

- 浏览
- 点赞
- 收藏
- 评论
- 私信
- 转化到题包/模考的人数

这样下次就能反推：

- 哪些考点适合做引流
- 哪些考点适合做收藏资料
- 哪些考点最容易带来训练转化


## 9. 推荐闭环

建议你按这条闭环跑：

`资料库/library -> 解析/题目/知识点 -> analysis 找热点 -> workflow 建选题 -> generate 出多版本 -> review 审查 -> history 发布复盘 -> question-bank/learners 承接训练 -> 学习数据再回流 analysis`


## 10. 当前最适合先做的内容组合

- `高频考点板块` 接 `真题拆解板块`
- `易错纠偏板块` 接 `训练提分板块`
- `速记资料板块` 接 `学习陪跑板块`

也就是：

- 先用“高频考点”把人吸引进来
- 再用“真题串讲”证明你专业
- 再用“题包/模考”完成承接
- 最后用“学习计划/复盘”把人留住
